## 3 已定死的决策（摘要）

| 决策 | 结论 |
| --- | --- |
| 形态 | 提权托盘单进程，不做服务 |
| 界面 | Qt Quick，明确要求美观，是界面面的第一优先级 |
| WebUI | 做，排在界面之后 |
| 触发策略 | 只记录，不自动封禁，封禁全部手工 |
| 白名单模式 | 做，且必须有超时自动回滚 |

| UDP 统计 | 走 ETW，不需要 WinDivert |
| IPv6 断连 | 先用丢包卡死兜底，按需再评估 |
| 跨平台 | 平台差异关进 `platform/`，接口分两层，禁止跨层引用 |
| 存储 | 规则与记录用 SQLite，配置用 JSON |
| 匹配模型 | 不做「可选目标与全系统」二分，统一为匹配条件：域内并集、域间交集、任意条件可取反；空条件不允许保存 |

完整清单与理由见 [architecture.md](architecture.md) 第 11 节。

## 6 环境与协作约定

### 6.1 文件位置

| 用途 | 位置 | 是否入库 |
| --- | --- | --- |
| 临时脚本、探测输出、环境速查 | `tmp/` | 否，已在 `.gitignore` 排除 |
| 规划与设计文档 | `docs/` | 是 |
| 构建产物 | `build/`、`out/` | 否 |

### 6.2 文档格式

- 项目文档使用**中文**
- 每次改完文档跑一次 markdownlint，命令见 `tmp/env-local.md`，**要求 0 错误**
- 已放宽的规则只有 MD013 行宽一项，理由是中文排版；其余规则一律靠正文合规满足
- 常见坑：表格分隔行要写 `| --- |` 且带空格；代码围栏必须带语言；标题、列表、表格、围栏前后都要空行；不要用独立成行的粗体当标题；同一文件内标题不能重复

### 6.3 并行编辑的教训

**同一文件的多次编辑必须串行提交。**
规划期曾并行提交五处编辑，结果段落互相插入、内容错乱，修了两轮才恢复干净。

### 6.4 代码风格与工程约定

| 项 | 约定 |
| --- | --- |
| 语言标准 | C++17，关闭编译器扩展 |
| 命名 | 类型用大驼峰，函数与方法用小驼峰，变量用小驼峰，私有成员尾随下划线 |
| 命名空间 | 一律落在 `baniphelper` 之下，再按层分 `core` 等子命名空间 |
| 包含路径 | 以 `src/` 为包含根，写成 `core/xxx.h` 与 `platform/api/xxx.h`，让依赖层次在 include 语句里直接可见 |
| 格式化 | 根目录 `.clang-format`，基风格 Google，手写代码后跑一次 |
| 注释 | 中文；解释「为什么」而不是复述「做什么」；接口头文件必须写明语义与不变量 |
| 构建 | 一律走 CMake 预设，不手写底层 cmake 命令；命令行构建所需的环境变量见 `tmp/env-local.md` |
| 工具链 | 只允许 Qt 套件自带的 MinGW，混用另一套会被顶层 `CMakeLists.txt` 直接拦下 |

## 7 开发环境推荐

### 7.1 写代码与调试

首选 **Qt Creator**（随 Qt 安装）：原生支持 CMake 与 Qt 自带的 MinGW，调试器集成好，
并且能直接以管理员身份启动被调试进程，这对提权托盘程序很关键。
VS Code 加 CMake 与 C++ 扩展也可用，但提权调试更麻烦。

### 7.2 命令行 shell

按用途分三档，不要用一个 shell 硬扛所有事：

| shell | 适合 | 不适合 |
| --- | --- | --- |
| Git Bash | 日常命令、构建脚本、需要可移植的脚本 | 调用 Windows 专有工具时路径转换易出错 |
| CMD | Windows 专有工具（`wevtutil`、`netsh` 等）与一次性命令 | 复杂脚本 |
| PowerShell | 需要 .NET 或 PS 模块时 | 作为默认脚本环境 |

PowerShell 的具体坑，以下均为本项目规划期实测踩到过的：

1. 多行命令粘贴常被当成多段执行，或卡在续行状态，需拆成单行或写进脚本文件
2. here-string 管道给外部程序不可靠
3. 双引号里的变量会被提前展开，传给外部程序时容易变成空值
4. `>` 重定向默认写 UTF-16，别的工具读会看到空字符
5. `&&` 不可用，只能用 `;`，而 `;` 不保证前一条成功

结论：**构建与脚本用 Git Bash，Windows 专有工具用 CMD，只有必须调 PowerShell 模块时才用它**。
若坚持用 PowerShell 做主环境，务必把命令写进脚本文件再执行，不要粘贴多行命令。

## 8 已知的坑

| 坑 | 说明 |
| --- | --- |
| 同一文件并行编辑 | 见 6.3，必须串行 |
| 提权进程调试 | 普通权限调试器无法附加，需以管理员身份启动调试器 |
| 退出后过滤器残留 | 过滤器在进程退出后仍在内核存活，启动清理必须有 |
| 清理误伤他方 | 只按自有 provider 与 sublayer 判断归属，绝不按层全量清理 |
| 白名单模式锁死自己 | 超时自动回滚不可关闭 |
| 断连后立刻重连 | 必须保证先封后断，否则对端会在被断的瞬间重连成功 |
